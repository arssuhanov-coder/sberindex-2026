# Прогнозирование инвестиций в основной капитал регионов РФ и обнаружение структурных изменений

Проект для конкурса **SberIndex 2026**. Решаются две задачи: прогнозирование инвестиций в основной капитал на год вперёд по 85 регионам РФ и обнаружение точек структурных изменений (Change Point Detection, CPD) во временных рядах инвестиций за 2002–2024 годы.

---

## 1. Данные

- **Источник:** БД ПМО Росстата через сервис tochno.st
- **Период:** 2002–2024 (23 года)
- **Уровень агрегации:** субъекты РФ
- **Число регионов:** 85 (после очистки от агрегатов «с автономными округами»)
- **Целевая переменная (target):** инвестиции в основной капитал (млн руб.)
- **Признаки:** оборот розничной торговли, среднедушевые доходы, уровень безработицы, ввод жилья, численность населения (с лагом 1)

### Обработка данных

- Сентинельные значения `-99999999` и `-77777777` заменены на `NA` на этапе сборки панели.
- Схема регионов: **«без автономных округов + сами АО»** для устранения территориального дублирования. Исключены агрегаты «Архангельская область (с АО)» и «Тюменская область (с АО)». Ненецкий АО, ХМАО и ЯНАО сохранены как самостоятельные регионы.

## 5. Модели

### Прогнозирование

- **Baseline:** для каждого региона выбирается лучшая из трёх моделей — Naive, MA3, MA5 (по минимальному sMAPE).
- **ARIMA:** автоподбор `(p, d, q)` из 8 кандидатов с валидацией на скользящих фолдах.
- **XGBoost:** панельная модель на лагах и rolling-статистиках. Логарифмирование таргета, TimeSeriesSplit внутри train.
- **Prophet:** отдельная модель на каждый регион, тренд + сезонность.
- **Chronos:** foundation-модель (`amazon/chronos-t5-small`), zero-shot.

### Change Point Detection

- **CUSUM** — кумулятивные суммы отклонений от среднего.
- **PELT** (`ruptures`, `model=l2`) — оптимальное разбиение со штрафом.
- **Binseg** (`ruptures`, `model=l2`) — бинарная сегментация.
- **Ансамбль:** точка считается консенсусной, если её нашли ≥ 2 метода из 3 в пределах ±1 год.

---

## 6. Валидация

- **Train:** 2002–2020 (1136 строк)
- **Test:** 2021–2024 (340 строк, 85 регионов × 4 года)
- **Внутри train:** Expanding Window TimeSeriesSplit (4 фолда, 2015–2020)
- **Предотвращение утечек:** все признаки сформированы через `shift(N)` по группе региона. Проверка на leakage выполнена: во всех лагах и rolling-статистиках значение для года t использует только годы ≤ t−1.

---

## 7. Метрики

- **MAE** — основная, в единицах таргета (млн руб.)
- **RMSE** — дополнительная, чувствительна к выбросам
- **sMAPE** — для сравнения регионов разного масштаба
- **R²** — коэффициент детерминации

Формула sMAPE:

```
sMAPE = (100% / n) × Σ 2|y_i - ŷ_i| / (|y_i| + |ŷ_i|)
```

## 8. Результаты прогнозирования

Средний sMAPE по 85 регионам (тест 2021–2024):

| Модель | sMAPE_mean | sMAPE_median | Лидер в регионах |
|---|---:|---:|---:|
| **XGBoost** | **15.82%** | 12.70% | **67** |
| Prophet | 28.44% | 25.87% | 9 |
| Baseline (лучший per region) | 34.20% | 34.19% | 5 |
| ARIMA | 36.00% | 34.19% | 1 |
| Chronos | 49.51% | 48.78% | 3 |

- XGBoost превзошёл Prophet в **67 из 85 регионов (79%)**.
- Chronos выиграл в 3 регионах (Москва, Вологодская, Астраханская), где инвестиции имеют специфическую динамику, не уловимую XGBoost.

## 9. Результаты CPD

- **Всего детекций:** 577 точек по всем регионам.
- **Консенсусных точек (≥ 2 метода):** 189.
- **Точек 3/3 консенсуса:** 47.
- **Регионов с хотя бы одной точкой 3/3:** 45 из 85.
- **Основные годы сдвигов:** 2003–2007 (рост перед кризисом 2008), 2015–2017 (замедление), 2020–2021 (COVID и санкции).


### Связь CPD и прогноза

После применения допуска ±1 год при ансамблировании CPD обнаруживается во всех 85 регионах. Сравнение групп «с CPD» и «без CPD» невозможно, так как вторая группа пуста.

Регионы разделены по силе сигнала CPD относительно медианы:

| Группа | Регионов | Mean sMAPE | Median sMAPE |
|---|---:|---:|---:|
| Strong CPD (сигнал > медианы) | 42 | 15.82% | 11.78% |
| Weak CPD (сигнал ≤ медианы) | 43 | 15.82% | 13.79% |

Mann-Whitney U test: **p = 0.2738**. Разница в качестве прогноза XGBoost между группами **статистически незначима** при пороге 0.05.

Корреляции между характеристиками CPD и качеством прогноза слабые (|r| < 0.2). Причинная связь между силой структурных сдвигов и качеством прогнозирования **не установлена**.

## 10. Ограничения

- **Короткие ряды:** 23 наблюдения на регион ограничивают глубину моделей.
- **Внешние признаки:** топ-3 признака XGBoost — это лаги самого таргета (52% важности). Внешние социально-экономические показатели дают менее 30%.
- **Масштаб Москвы:** инвестиции в 10–20 раз выше среднего, что создаёт сложности при обучении.
- **Годовая частота:** горизонты 1, 3 и 6 месяцев недоступны без перехода на месячные данные. Прогноз выполнен на 1 год, что эквивалентно 12 месяцам.
- **Интеграция новостных данных** не реализована — обозначена как перспектива развития.
