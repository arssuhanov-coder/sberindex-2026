# Словарь данных (Data Dictionary)

## 1. Панель региональных данных

**Файл:** `data/processed/panel.parquet`  
**Строк:** ~1955 (85 регионов × 23 года)  
**Период:** 2002–2024  
**Регионов:** 85

### Поля

| Поле | Тип | Единица | Источник (код Росстата) | Период |
|---|---|---|---|---|
| region | str | — | tochno.st | 2002–2024 |
| year | int | год | tochno.st | 2002–2024 |
| investments | float | млн руб. | Y477110107 | 2002–2024 |
| retail | float | млн руб. | Y477110223 | 2002–2024 |
| income | float | руб./мес. | Y477110374 | 2002–2024 |
| unemployment | float | % | Y477110418 | 2002–2024 |
| housing | float | тыс. кв. м | Y477110016 | 2002–2024 |
| population_lag1 | float | тыс. чел. | Y477110373 | 2001–2023 |

### Описание показателей

- **investments** — инвестиции в основной капитал. Основной таргет. Единица: млн рублей.
- **retail** — оборот розничной торговли. Единица: млн рублей.
- **income** — среднедушевые денежные доходы населения. Единица: рублей в месяц.
- **unemployment** — уровень безработицы. Единица: процент.
- **housing** — ввод в действие жилых домов. Единица: тыс. кв. м.
- **population_lag1** — среднегодовая численность населения с лагом 1 год. Единица: тыс. человек.

## 2. Обработка сентинелов

В исходном датасете БД ПМО Росстата пропуски кодируются значениями `-99999999` и `-77777777`. На этапе сборки панели (см. `src/data/build_panel.py`) они заменены на `NA`. В финальной панели сентинелов нет.

## 3. Схема регионов

Панель использует схему «без автономных округов + сами АО» для устранения территориального дублирования.

**Исключены агрегатные ряды:**
- Архангельская область (с автономным округом)
- Тюменская область (с автономными округами)

**Включены как самостоятельные регионы:**
- Ненецкий автономный округ
- Ханты-Мансийский автономный округ — Югра
- Ямало-Ненецкий автономный округ

**Итоговое число регионов:** 85.

## 4. Матрица признаков

**Файл:** `data/processed/features_forecast.parquet`  
**Колонок:** 31

Содержит:

- **Исходные показатели:** investments, retail, income, unemployment, housing, population_lag1.
- **Лаги таргета:** investments_lag1, investments_lag2, investments_lag3.
- **Лаги внешних признаков:** `{retail|income|unemployment|housing|population_lag1}_lag{1|2|3}`.
- **Скользящие статистики:** investments_roll_mean_3, investments_roll_mean_5, investments_roll_std_3.
- **Разность:** investments_diff1.
- **Логарифм лага:** investments_log_lag1.

**Формирование:** все лаги через `groupby("region").shift(N)`. Перед rolling-статистиками применён `shift(1)` во избежание утечки будущих значений. Проверено: `investments_lag1(t) = investments(t-1)`, `roll_mean_3(t)` = среднее за t-1, t-2, t-3.

## 5. Метрики

- **MAE** — средняя абсолютная ошибка, в единицах таргета (млн руб.).
- **RMSE** — корень из среднеквадратичной ошибки, в единицах таргета.
- **sMAPE** — симметричная средняя абсолютная процентная ошибка, в %.
- **R²** — коэффициент детерминации.

Формула sMAPE:

```
sMAPE = (100% / n) × Σ 2|y_i - ŷ_i| / (|y_i| + |ŷ_i|)
```
